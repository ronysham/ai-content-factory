About AI Content Factory

AI Content Factory is an independently developed, development-stage content intelligence and original video production application. It is currently operated locally by its developer and is not currently offered as a public software service.

YouTube API Services

AI Content Factory uses YouTube API Services to access publicly available video metadata and statistics for content research, trend analysis, and related analytical functions.

Use of YouTube API Services is subject to the YouTube Terms of Service and applicable Google and YouTube API Services policies.

Google's Privacy Policy is available at https://policies.google.com/privacy .

Purpose of the Application

The application uses publicly available content signals to assist with identifying topics for further research and potential original content creation.

YouTube API data may be used for trend analysis, topic comparison, content opportunity analysis, and other internal analytical functions related to original content production.

Original Content and YouTube Videos

YouTube videos discovered through the API are used as research and trend signals. AI Content Factory does not use the YouTube Data API to download or redistribute YouTube videos.

Content selected for production undergoes separate research and fact-checking before original scripts and video assets are produced.

API Data

YouTube API data is intended to be handled in accordance with the YouTube API Services Terms of Service and applicable Developer Policies, including requirements relating to access, storage, refresh, deletion, and use of API data.

Current Access

AI Content Factory currently has no public user accounts and does not require users to authenticate with a Google or YouTube account. The current application accesses public YouTube information through the YouTube Data API.
