Privacy Policy

Last updated: September 19, 2026

This Privacy Policy describes how AI Content Factory accesses and uses information in connection with its content intelligence and original video production functions.

About AI Content Factory

AI Content Factory is an independently developed, development-stage software application used by its developer for content research, content intelligence, and original video production.

The application is currently operated locally and is not offered as a public service.

YouTube API Services

AI Content Factory uses YouTube API Services. By using functionality involving YouTube API Services, applicable use is also subject to the Google Privacy Policy and YouTube's Terms of Service.

Google Privacy Policy: https://policies.google.com/privacy

YouTube Terms of Service: https://www.youtube.com/t/terms

Information Accessed Through the YouTube Data API

The application accesses publicly available YouTube data through the YouTube Data API for content research and analysis.

This may include public information such as video identifiers, titles, publication dates and times, view counts, like counts, comment counts, and other public metadata returned by the API.

How YouTube Data Is Used

Public YouTube data is used to discover recent content, analyze trends, compare related topics, evaluate content opportunities, measure changes in publicly available statistics, and prioritize subjects for further independent research and original content production.

The application may calculate internal analytical indicators from public API data to assist with content research and decision-making.

Data Storage

During development, public metadata and statistics obtained through the YouTube Data API may be stored locally for analysis, comparison, testing, and measurement over time.

AI Content Factory is intended to handle YouTube API data in accordance with applicable YouTube API Services Terms of Service and Developer Policies, including applicable requirements concerning storage, refresh, deletion, and use of API data.

Data Retention and Deletion

YouTube API data is retained only as necessary for the application's permitted research and analytics functions and is handled in accordance with applicable YouTube API Services policies and any permissions granted to the application.

Data that is no longer required for a permitted purpose, or that must be deleted or refreshed under applicable YouTube API Services policies, will be deleted or refreshed as required.

The current application does not access Google or YouTube user data through OAuth and therefore does not currently retain private authenticated YouTube account data or OAuth tokens.

YouTube Account and User Data

The current version of AI Content Factory uses API access for public YouTube data and does not provide user sign-in with a YouTube account. It does not currently request OAuth authorization to access a user's private YouTube account data.

Downloading and Redistribution

AI Content Factory does not use the YouTube Data API to download or redistribute YouTube videos. Videos discovered through the API are used as research and trend signals for the creation of original content.

Sharing of Data

The application is currently a private development project and does not sell YouTube API data or provide YouTube API data to external customers.

Future Changes

If AI Content Factory introduces public user accounts, YouTube OAuth authorization, or materially changes how it collects or uses data, this Privacy Policy will be updated to reflect those changes.

Contact

Questions regarding this Privacy Policy may be directed to the project owner through the public project repository.
